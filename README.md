A one-star review of Monday, written as if Monday were a restaurant — 120 characters, 24 words, one line.

> One star. The hostess sat me by the printer, my coffee arrived at 4 p.m., and the chef sent a second Monday for dessert.

Run `node main.ts` to write the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
